# ZOMKILL V.0.1
- This is the first versionof the game ZOMKILL, there is only one level so far.
- The Game is simple, you need to punch the zombies and kill them.
## Controllers
- Click the mouse left or right button or press the E button to attack.
- Also you can run by pressing the shift button
- And use D and A to move and SPACE to jump
