# ZOMKILL V.0.2
- ZOMKILL is a 2D platformer game with 5 levels. Complete all the objectives to win each level!
- The primary challenge is to jump between platforms and punch the zombies to kill them and collect all the coins.
- This is the second version of the game, so I added many new features to it.
- I used assets called Oak Woods on itch.io it was free when i used it.
- I wanted to make a good game that i can enjoy building it in my free time and this kinda inspired me.


## How To Run The Game?
- To run the game you should open the itch.io link, then click the button "Run Game". So simple.

## How To Play The Game?
- To play the game correctly, you should click the "Start Game" button in the main menu after running the game. Then select the one of the 5 levels.
- As I said before, the only way to complete the level is by defeating all the zombies by using any punch you want, and collecting all the coins.
- All the punches have same damage effect on the zombies.
- If get too close to the zombies, they will prepare to attack you and their speed will increase untill they strike.
- You must prevent them from successfully attacking you 5 times, or you will lose.
- Each of zombies in every level needs two successful punches to kill them.

## Controllers
- Movement is controlled using A and D or the ← and → arrow keys to move the character horizontally across the level and you can hold shift to run.
- The player can jump using the spacebar.
- You can attack using the LMB for the cross punch or the RMB for the hook punch or E for the uppercut key.
