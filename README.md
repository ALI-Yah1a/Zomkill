# ZOMKILL V.0.1
- A 2D platformer where you conquer an exciting level. Complete all the objectives to win the game!
- Where the primary challenge is navigating a character through a map filled with platforms and enemies. Player must jump between platforms and punch the zombies to kill them.
- This is the first version of the game, so there is only one objective and one level.
- I used assets called Oak Woods on itch.io it was free when i used it.
- I wanted to make a good game that i can enjoy building it in my free time and this kinda inspired me.
- *Wait for future updates..*

## How To Run The Game?
- To run the game you should open the itch.io link, then click the button "Run Game". So simple.

## How To Play The Game?
- To play the game correctly, you should click the "Start Game" button in the main menu after running the game. Then select the only level existed untill now.
- As I said before, the only way to complete the level is by defeating all the zombies by using any punch you want, you can use the simple cross or the hook or the uppercut.
- All the punches have same damage effect on the zombies.
- If get too close to the zombies, they will prepare to attack you and their speed will increase untill they strike.
- You must prevent them from successfully attacking you 5 times, or you will lose.
- Each of the 13 zombies in this level needs two successful punches to kill them.

## Controllers
- Movement is controlled using A and D or the ← and → arrow keys to move the character horizontally across the level and you can hold shift to run.
- The player can jump using the spacebar.
- Attacks are performed using the LMB for the cross punch or the RMB for the hook punch or E for the uppercut key.
